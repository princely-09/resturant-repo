Marked with a green checkmark, this step shows the timestamp when the restaurant accepted the order (e.g. 2:14 PM).
Step 2 — Preparing Your Food ✓ Done
Also marked complete, this step confirms the kitchen has started on the order, timestamped a few minutes after confirmation (e.g. 2:19 PM).
Step 3 — Out for Delivery 🛵 Active
The currently active step, highlighted in orange. A animated rider icon on the map above moves along the route to reflect this live status, showing "Now" as the time.
Step 4 — Delivered 📍 Pending
The final step, shown in a muted/inactive state with an estimated arrival time (e.g. ~2:38 PM). It updates to complete once the order arrives.
Each step uses a circular icon that changes color based on state — green for done, orange for active, and grey for pending — giving users an instant visual read of where their order is at a glance.
